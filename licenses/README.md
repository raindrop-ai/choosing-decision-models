# Source terms and notices

This repository collects separately licensed question materials. **There is no blanket license for the questions.** Each released record identifies its source and terms.

- Original source notices are retained under [`sources/`](sources/).
- [The sharing audit](../docs/data-sharing.md) explains included and held sources.
- [`data/sources.json`](../data/sources.json) records attribution, evidence URLs, original hashes, and data-versus-code distinctions.

CLUTRR, EmoWOZ and ToxicChat materials retain [CC BY-NC 4.0](CC-BY-NC-4.0.txt), including the noncommercial restriction. Their inclusion reflects the stated noncommercial purpose of this research release.

Normalization and answer-choice adaptations are disclosed in each released record. In particular, adapted SelfAware entries retain **CC BY-SA 4.0**, not the upstream code's Apache license.

Downloaded model code and weights retain their publishers’ terms. Raindrop names and brand artwork remain the property of their owners.
