# Data sharing decisions

Each dataset’s terms still apply. In the table below, **Included** means we provide the question text. **Recover locally** means you download the original files and use our tools to reconstruct the questions we used. We checked the source terms on November 9, 2026.

The collection keeps all 1,005 original-question metadata records and all 13,065 baseline outcomes. Full inputs are bundled for 857 questions; the other 148 can be reconstructed locally from original source files under the source terms. Recovered question texts stay in the ignored `.local/` folder and are not redistributed with the repository.

## Attribution and adaptation

CLUTRR, EmoWOZ and ToxicChat question material is included for this noncommercial research release under CC BY-NC 4.0. Its noncommercial restriction remains applicable to downstream reuse. The full license and disclaimer are in [`licenses/CC-BY-NC-4.0.txt`](../licenses/CC-BY-NC-4.0.txt).

Question records retain the source URL, revision when available, original locator, attribution, and per-source license. Where the evaluated choice format differs from the source question, released records also include the native representation. Adapted SelfAware entries remain under CC BY-SA 4.0; BoolQ entries retain CC BY-SA 3.0. Per-question Wikipedia, OANC, BIG-bench and component attribution is recorded in [`data/source_attributions.json`](../data/source_attributions.json) and displayed on the question pages. This is a collection of separately licensed source materials; there is no blanket MIT license for the questions.

The original license notices are in [`licenses/sources/`](../licenses/sources/). [`data/sources.json`](../data/sources.json) records checked evidence URLs, source hashes, and license excerpts. [`data/sharing_decisions.csv`](../data/sharing_decisions.csv) gives a decision for each of the 1,005 question IDs.

Publisher dataset-card declarations and source credits are recorded in `data/sources.json`. Follow each source’s terms when obtaining or reusing its text.
