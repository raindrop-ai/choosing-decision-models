# Browse the baseline questions

Each capability links to question pages with sources and all 13 recorded model outcomes. The last column counts questions whose complete text is included in this repository.

The questions come from datasets with different licenses. We include full text where the source terms clearly allow us to share it here. For 148 questions, permission to republish the text is unclear or additional license requirements apply. We therefore provide [original download links and recovery tools](../docs/recovering-inputs.md) so readers can obtain those questions from their sources instead.

All 1,005 questions still have their IDs, reference answer keys and recorded model results included. You can verify the reported scores without downloading the missing texts.
