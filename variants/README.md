# Explore the question variants

The study contains **24,563 altered versions of the 1,005 original questions**, tested on 11 decision models. Each version keeps the recorded reference answer. Start from a capability, choose an original question, then open one of its variants.

[How the variants were made](../docs/variant-methods.md) · [Read the results](../docs/variant-results.md) · [Verify or rerun](../docs/variant-reproduction.md) · [Original questions](../questions/README.md)

Full text is included for **20,961 variants**. The other **3,602** use original question texts with additional sharing requirements; [recover them locally](../docs/variant-reproduction.md#recover-the-remaining-variant-texts) from the original sources and saved edit recipes. All variant IDs, reference keys and recorded outcomes are included.
